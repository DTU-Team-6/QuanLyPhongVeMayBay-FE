# Quản lý phòng vé máy bay — Frontend

Dự án sử dụng React, Vite và JavaScript.

## Yêu cầu

Node.js 20.19+ (nhánh 20) hoặc 22.12+ và npm.

## Chạy dự án

```bash
npm install
npm run dev
```

Mở địa chỉ do Vite hiển thị trong terminal (mặc định http://localhost:5173).
Chỉnh sửa giao diện tại `src/App.jsx`; điểm khởi động React là `src/main.jsx`.

## Build production

```bash
npm run build
npm run preview
```

Bản build nằm trong thư mục `dist/`. Lệnh `preview` chỉ dùng kiểm tra bản build trên máy local.
